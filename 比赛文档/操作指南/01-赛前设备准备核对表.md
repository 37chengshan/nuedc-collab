# 赛前设备准备核对表

本表只验证设备能力、连线、安全与记录能力；不预设赛题、运动策略、目标物或最终系统架构。每一项填写“通过 / 不通过 / 未检查”，异常立即创建问题记录，不用口头结论替代。

## 通用安全与记录

- [ ] 设备均有编号或可辨识标签，电池、充电器和工具归位。
- [ ] 有万用表、限流电源/保护措施、常用线材和绝缘/固定材料。
- [ ] 操作前拍照记录关键接线；操作后把照片、日志或读数关联到任务/问题事件。
- [ ] 高电流上电前已检查极性、短路和共地关系。
- [ ] 急停/断电动作对操作者可达；电机和轮组附近无松散线束。

## 小车平台

- [ ] 轮组、紧固件、编码器和线束固定；轮子空转无明显机械干涉。
- [ ] 电池极性、保险/限流措施、各电源域与共地策略已检查。
- [ ] 电机驱动每个通道先空载测试，再在安全条件下带载；记录电流和异常。
- [ ] 预留接口（灰度、IMU、舵机、串口设备）方向、线长和插拔可靠性已检查。
- [ ] 断电后再次目检，无松动、过热、异味或损伤。

## 天猛星 / 地猛星与 MSPM0

- [ ] 核心板和主板的 J5/J6、J33/J34 等已按实际板卡核对，连接可靠。
- [ ] 按实际硬件资料分电源域上电并测量：3.3V、5V、7.4V、12V、SERVO_5V；没有读数不填“通过”。
- [ ] SWD 下载和最小程序（如点灯）可用，保存日志或照片。
- [ ] 串口收发已验证；编码器等外设仅记录已验证的接口，不猜测引脚复用。
- [ ] 电机驱动先空载、后带载；任何异常建立问题，不反复强行上电。
- [ ] 未确认极性时不连接电池大电流；先焊阻容和电源，再插核心板。

## K230 视觉

- [ ] K230、摄像头、TF 卡、供电和线材状态正常；记录固件/工具链版本。
- [ ] CanMV 脚本能启动并保存启动日志；确认基础串口输出通路。
- [ ] 记录摄像头安装高度、视野、曝光和线材抗干扰等实机现象。
- [ ] 参考代码仅按其 LICENSE、SOURCE 和固定版本使用；不把参考检测任务当作比赛题目。
- [ ] 未把大型模型、权重或不明来源数据直接复制进主仓库。
- [ ] 不使用上游标注为“不要部署”的历史候选模型。

## 最小联调与收尾

- [ ] 仅在安全条件下验证视觉输出与控制侧接收的基本通路；不把此项写成最终通信协议。
- [ ] 每项通过都有可追溯证据；失败项都已建问题、指定 owner 和下一步。
- [ ] 已把今日检验结果写成 `testResult` 事件，必要时关联任务和提交。
- [ ] 离场前断开电池/大电流电源，设备归位，清点存储卡和下载线。
