# 天猛星 / 地猛星（赛前方向）

## 角色边界（暂定能力，不是最终架构）

- **天猛星（MSPM0 核心板方向）**：实时控制、PWM、编码器、状态机、急停与底层外设。
- **地猛星 / 底板互联方向**：电源分配、电机驱动座、传感器汇聚、调试接口引出。

具体主从分工、通信协议和任务分配等**题目公布后再定**。

## 赛前准备

1. 确认核心板与主板 J5/J6、J33/J34 等连接可靠。
2. 分电源域上电：3.3V / 5V / 7.4V / 12V / SERVO_5V。
3. 串口与 SWD 调试链路打通，保存最小点灯/读编码器样例结果。
4. 任何不确定的引脚复用只记入问题/想法，不固化为“比赛方案”。
