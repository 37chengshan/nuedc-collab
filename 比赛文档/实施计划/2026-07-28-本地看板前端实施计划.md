# 本地看板前端 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`（推荐）or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 交付 `apps/dashboard` 本地协作看板：React/Vite/TypeScript/Tailwind 设计 token、八个真实页面、全部通过本地 API 读写、Claude 陶土橙产品壳、Git 五步人工确认、agent-native 能力页，以及 Vitest/RTL、Playwright、axe、响应式与首屏体积验收。

**架构：** 前端只消费 `apps/server` 已交付的 localhost API。`src/api` 负责会话头、错误映射与 typed client；`src/features/*` 按页面组织 query/mutation 与视图；`src/components` 承载应用壳、状态面、抽屉/对话框与 Git 确认向导；领域校验、幂等、revision、owner 与 Git 写安全全部留在服务端。网页不得复制 Schema 或直接访问文件系统。

**技术栈：** React 19、Vite 6、TypeScript 5、Tailwind CSS 4（CSS 变量 token）、React Router 7、TanStack Query 5、dnd-kit（仅任务看板拖拽）、Lucide React、Vitest、React Testing Library、Playwright、@axe-core/playwright。禁止 framer-motion、GSAP、Lottie 或其他大型动画运行时。

## 全局约束

- 本计划仅创建或修改 `apps/dashboard/**`，以及为 dashboard 注册所需的根 workspace 脚本（若根 `package.json` 尚无 `@nuedc/dashboard` workspace 引用）。不得修改 `apps/server/**`、`packages/**`、设计规范、阶段一/二计划或原型 HTML。
- 所有网页读写必须走 API：`/api/health`、资源 GET/POST/PUT、`/api/actions/:action`、`/api/capabilities`、`/api/schemas/actions/:action`、Git 只读与确认写端点、资料/设计端点、设置端点。禁止 `fs`、子进程、直接读 JSON 文件。
- 网页不得实现领域 Schema 校验副本；客户端只做 UX 必填提示，最终以服务端 `ACTION_VALIDATION_FAILED` / `STALE_ENTITY` / `OWNER_MISMATCH` 等稳定错误码为准。
- 13 个领域动作固定为：`task.create`、`task.update`、`task.setStatus`、`task.handoff`、`issue.create`、`issue.update`、`issue.handoff`、`event.append`、`idea.create`、`idea.update`、`idea.promoteToTask`、`member.update`、`settings.update`。通用动作集合永远不含 `git.*`。
- Git 拉取/提交/推送必须走独立五步确认：`查看 → 填写 → 复核 → 确认 → 结果`；写请求必须带 `confirmed: true` 与确认页记录的 `expectedHead` / `expectedRemoteHead` / `expectedChangesHash`；状态变化时展示 `409 STALE_GIT_STATE` 中文影响与下一步，不自动重试写操作。
- 设置页 `confirmGitWrites` 只读展示为固定开启；客户端尝试修改时不得发送该字段。
- 颜色、字体、时长、断点必须与设计规范 §9 一致：陶土橙 `#D97757`、暖白画布 `#F7F5F2`、合法衬线标题栈与中文无衬线正文栈；动效只改 `transform`/`opacity`；`motionLevel` 为 `system | none | reduced | standard`。
- 每个可进入控件覆盖 idle/hover/active/focus-visible/loading/empty/error/disabled/selected-success/overflow。对话框与抽屉捕获焦点，Escape 关闭，关闭后焦点回到触发器。
- 响应式验收断点固定：320、375、768、1024、1440、2560。1024 起保留侧栏；小于 1024 使用等价导航且不隐藏 Git 风险。触控目标 ≥44×44px；≤640 表单控件字号 ≥16px。
- 路由拆包；首屏 gzip JS 总量 ≤250KiB；焊接教程、差异查看器、系统画布懒加载。浏览器脚本执行核心操作流时不得出现超过 100ms 的非测试注入长任务。
- 测试命令优先使用 `rtk`：`rtk npm run test --workspace=@nuedc/dashboard`、`rtk npx playwright test` 等。每个任务结束时本地提交；不推送。
- 禁止占位：不得出现未完成标记、模糊引用、静态假数据冒充 API 或空实现按钮。

## 前端接口契约

```ts
// apps/dashboard/src/api/types.ts
export type DomainActionName =
  | "task.create"
  | "task.update"
  | "task.setStatus"
  | "task.handoff"
  | "issue.create"
  | "issue.update"
  | "issue.handoff"
  | "event.append"
  | "idea.create"
  | "idea.update"
  | "idea.promoteToTask"
  | "member.update"
  | "settings.update";

export interface RecordEnvelope<T = Record<string, unknown>> {
  data: T;
  relativePath: string;
  revision: string;
  effectiveState?: string;
}

export interface ActionRequest {
  idempotencyKey: string;
  expectedRevision?: string;
  payload: Record<string, unknown>;
}

export interface ActionSuccess {
  ok: true;
  action: DomainActionName;
  idempotencyKey: string;
  idempotentReplay: boolean;
  entities: Array<{
    recordType: "task" | "issue" | "idea" | "event" | "member" | "settings";
    id: string;
    relativePath: string;
    revision: string;
    updatedAt?: string;
  }>;
  warnings: Array<{ code: string; message: string; target?: string }>;
  nextActions: Array<{
    action: DomainActionName | "git.commit" | "git.pull" | "git.push";
    label: string;
    confirmationPolicy: "none" | "human";
  }>;
}

export interface ActionFailure {
  ok: false;
  code:
    | "ACTION_VALIDATION_FAILED"
    | "ACTION_NOT_SUPPORTED"
    | "STALE_ENTITY"
    | "IDEMPOTENCY_KEY_REUSED"
    | "OWNER_MISMATCH"
    | "INACTIVE_MEMBER"
    | "PROMOTED_TASK_ALREADY_EXISTS";
  action: DomainActionName;
  idempotencyKey: string;
  error: { impact: string; nextStep: string; details: string };
  latestEntity?: RecordEnvelope;
  warnings: Array<{ code: string; message: string; target?: string }>;
  nextActions: Array<{ action: string; label: string; confirmationPolicy: "none" | "human" }>;
}

export interface CapabilitiesResponse {
  protocolVersion: 1;
  actor: string;
  actions: Array<{
    name: DomainActionName;
    description: string;
    requiresRevision: boolean;
    requiresIdempotencyKey: true;
    schemaRef: string;
  }>;
  domAutomationAllowed: false;
  directFileMutationAllowed: false;
  gitConfirmationRequired: true;
}

export interface GitState {
  worktree: "clean" | "dirty" | "conflict";
  topology: "unborn" | "noRemote" | "synced" | "ahead" | "behind" | "diverged";
  connection: "online" | "networkError" | "authError";
  head: string | null;
  remoteHead: string | null;
  ahead: number;
  behind: number;
  severity:
    | "conflict"
    | "unborn"
    | "noRemote"
    | "networkError"
    | "authError"
    | "diverged"
    | "behind"
    | "ahead"
    | "dirty"
    | "clean";
  lastCheckedAt: string;
}

export type GitWizardKind = "pull" | "commit" | "push";
export type GitWizardStep = "view" | "fill" | "review" | "confirm" | "result";

export interface LocalSettings {
  githubUsername: string;
  port: number;
  autoFetchIntervalSeconds: number;
  motionLevel: "system" | "none" | "reduced" | "standard";
  confirmGitWrites: true;
}

export type TaskStatus = "todo" | "doing" | "blocked" | "review" | "done";
export type TaskBoardColumn = "todo" | "doing" | "review" | "done"; // blocked 归入 doing 列并显示红标
```

```ts
  step: GitWizardStep;
  snapshot: GitState;
  files?: string[];
  message?: string;
  expectedChangesHash?: string;
  result?: { ok: boolean; code?: string; impact?: string; nextStep?: string };
```

步骤规则：

1. **查看**：只读展示 status/diff/log 摘要，调用 `getGitStatus`/`getGitDiff`，不写。
2. **填写**：commit 必选 1—200 文件与 1—500 字 message；pull/push 展示固定 `origin/main` 目标，无自由分支输入。
3. **复核**：展示影响数量、expectedHead/remoteHead/changesHash、可逆性说明、失败处理。
4. **确认**：用户点击具体动词按钮“确认快进拉取”/“确认创建本地提交”/“确认推送到 origin/main”，此时才 `POST` 写 API，body 含 `confirmed: true` 与期望值。
5. **结果**：成功展示新状态；`STALE_GIT_STATE`/`DIVERGED_HISTORY`/`NETWORK_ERROR`/`GIT_AUTH_ERROR` 停止并中文指引，不自动重试。
