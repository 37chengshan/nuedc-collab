## 2. 坐标系、站点与距离口径

门锁圆心为坐标原点 `O=(0,0)`，正前方为 `+y`，右侧为 `+x`，角度以正前方为 `0°`，右侧为正角、左侧为负角。

| 站点 | 采集设备 | 地址 | 坐标/mm | 约定 |
| --- | --- | --- | ---: | --- |
| 右站 | `device1` | `0100` | `(+72.5, 0)` | 模型特征记为 `uR`、原型记为 `pR` |
| 左站 | `device2` | `0200` | `(-72.5, 0)` | 模型特征记为 `uL`、原型记为 `pL` |

两站天线中心基线为 `145 mm`，不得按旧配置误写为 `125 mm` 或 `250 mm`。

官方径向零点为：

```text
R0 = 300 mm
```

若 `r` 为门锁圆心到钥匙参考中心的半径，则比赛距离口径为：

```text
d = r - R0
r = d + R0
```

本文物理点距离、原型真值和模型输出均按比赛距离 `d` 记录。部署时不得在模型输出端再次重复加减 `300 mm`。

## 4. 0.8 s lower-3 特征

实时候选算法每 `100 ms` 更新一次。两站数据按同一钥匙目标地址和
不超过 `120 ms` 的时间差配对，每站维护最近 `0.8 s` 的有效样本。

本轮标定原始帧中的 `0100/0200` 是右/左站点链路地址，不是钥匙
身份地址。离线数据只有一个受控目标，因此可以完成测距标定；生产
固件则把 `station_addr` 与 `key_addr` 分开。仅有 `P0/P1` 站点
地址的帧可以输出距离，但 `key_id_valid=false`，不得开锁。两路
独立钥匙地址不一致或发生切换时清空历史，禁止跨目标混算。

对每站窗口内距离按升序排列，取最小 3 个值的均值：

```text
uR = mean(lowest3(device1/right))
uL = mean(lowest3(device2/left))
```

每路至少需要 3 个样本才能形成特征；质量门中的高置信样本要求为每路至少 6 个。lower-3 用于抑制正向多径拖尾，但不能消除落入错误物理点邻域的持续别名。

## 5. 43 点二维 4NN 距离模型

### 5.1 距离公式

对第 `i` 个物理点原型，计算归一化平方距离：

```text
q_i = ((uR - pR_i) / 1318.28)^2
    + ((uL - pL_i) / 2045.99)^2
```

固定尺度为：

```text
scale_device1_right = 1318.28 mm
scale_device2_left  = 2045.99 mm
neighbor_count      = 4
```

选择 `q_i` 最小的 4 个原型，使用逆距离权重：

```text
w_i = 1 / max(q_i, 0.0004)

distance_mm =
  clamp(
    sum(w_i * true_distance_i) / sum(w_i),
    800,
    3000
  )
```

当前候选使用纯二维 4NN，不与旧的一号链路单调折线混合。冻结表
实际保存 `{pR, pL, true_distance, true_angle}`：前三项参与距离
估计，角度列只用于两个诊断候选的分桶、数据追溯和别名分析。

## 6. 距离质量分级

距离结果必须同时输出 `HIGH`、`MEDIUM` 或 `REJECT`，不能只输出一个无质量信息的距离数值。

### 6.1 HIGH

全部满足时判为 `HIGH`：

```text
nR >= 6 且 nL >= 6
MADR <= 50 mm 且 MADL <= 50 mm
device2/left SNR >= -5 dB
abs(uL - uR) <= 300 mm
min(q_i) <= 0.4
四近邻真值距离跨度 <= 400 mm
连续 3 个窗口的相邻结果变化 <= 150 mm
```

`HIGH` 才允许参与解锁距离判断。

### 6.2 MEDIUM

全部满足时判为 `MEDIUM`：

```text
nR >= 5 且 nL >= 5
MADR <= 100 mm 且 MADL <= 100 mm
device2/left SNR >= -6 dB
abs(uL - uR) <= 500 mm
四近邻真值距离跨度 <= 400 mm
```

`MEDIUM` 只允许显示距离，不允许触发解锁。

### 6.3 REJECT

其余情况判为 `REJECT`。可以短时保持上一可信距离，但超过 `500 ms` 后必须置为无效；`REJECT` 不参与解锁。

## 8. 角度评估与不可辨识结论

离线分析中表现最好的静态点估计候选使用两路低分位差：

```text
x = (q05_left - q05_right)
  / ((q05_left + q05_right) / 2)

angle_deg =
  clip(
    11.19 + 94.53*x - 247.96*x^2 - 386.40*x^3,
    -45,
    +45
  )
```

物理点整组留出指标为：

```text
MAE       = 18.25°
P95       = 32.87°
最大误差  = 58.37°
R^2       = 0.503
```

两站 145 mm 基线存在直接的同测量异角证据：

| 物理点 | `pR` device1/mm | `pL` device2/mm |
| --- | ---: | ---: |
| `2.0 m / -15°` | 1803 | 2002 |
| `2.0 m / +40°` | 1837 | 2020 |

两组原型仅相差 `34 mm / 18 mm`，却对应相差 `55°` 的真实角度。该差异小于单窗常用波动门限，说明两站当前观测不能稳定区分这两个角度，增加平滑不能恢复已经缺失的空间可辨识性。

因此生产口径固定为：

```text
angleValid = false
```

角度不得参与解锁、方向限制或安全决策。可以在日志中保留两个角度候选或 15° 分桶结果用于诊断，但不得包装成可信单值角度。
