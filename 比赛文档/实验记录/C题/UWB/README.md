# C 题 UWB 实验记录

本目录保存 EWM/EWT550 到货鉴定、AT 配置、一主多从链路、测距、定位和抗多径测试的正式记录。

## 证据要求

- 原始串口日志不得只保留截图，应保存未经修改的文本或二进制采集文件。
- 每次实验记录日期、操作者 GitHub username、模块丝印、固件版本、角色、地址、供电、电平、串口参数和接线。
- 测距数据记录三个固定节点的原始距离、接收时间戳、主机地址、解析状态、定位结果、残差、区域和锁态。
- 构建通过、串口收到数据、完成测距、完成定位和通过比赛指标必须分别表述。
- 原始数据不得为了“看起来稳定”而删除；异常数据应增加标记并说明原因。

## 推荐文件命名

```text
YYYYMMDD_HHMM_一主一从_原始串口.log
YYYYMMDD_HHMM_一主三从_测距.csv
YYYYMMDD_HHMM_定位回归.csv
YYYYMMDD_HHMM_实验记录.md
```

## 实验顺序

1. 到货板型、电源和逻辑电平鉴定。
2. 单模块进入配置模式，查询固件、角色、地址和从机数量。
3. 一主一从确认数据格式、单位、更新率和掉电保持。
4. 一主二从确认轮询与标签输出独立性。
5. 一主三从记录三个固定节点的连续原始日志。
6. 完成 0.5 m、1 m、2 m、3 m 和 `0°、±15°、±30°、±45°` 测试。
7. 完成 1 m、2 m 边界双向测试以及靠墙、靠桌、人员位于背面的多径测试。
