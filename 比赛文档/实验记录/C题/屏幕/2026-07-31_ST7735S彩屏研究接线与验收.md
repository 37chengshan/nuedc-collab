## 1. 需求解释

题目“要求 1”中的密码不是普通字符串密码，而是数字钥匙发送的 4 位身份 ID。
门锁端设定 ID 和接收到的钥匙 ID 都必须按 4 位二进制显示并保留前导零，例如
十进制 2 显示为 `0010`。

显示数据包括：

- `SET ID`：PB0～PB3 读取的门锁设定身份 ID；
- `KEY ID`：UWB 数据帧中的钥匙身份 ID，无有效帧时显示 `----`；
- `AUTH`：`PASS`、`FAIL` 或 `WAIT`；
- `ANGLE`：只有至少 3 个有效锚点参与测量时才可信；
- `DIST`：距门锁边界的距离；
- `ZONE`：区域判定；
- `LOCKED/OPEN`：锁状态。

两锚点角度始终保留一个显示值：有新估计时更新，不可信时保持上次，上电没有
历史值时显示 0°。该值只供显示，`angle_valid` 仍保持 false，不能参与开锁。

## 2. 资料研究结论

本地资料 `LCD_Config.h` 明确分辨率为 128×160。`Lcd_Driver.c` 和
ST7735S 数据手册共同确认了以下关键流程：

1. 硬件复位；
2. 退出睡眠 `0x11`；
3. 设置 16 bit RGB565：`0x3A, 0x05`；
4. 设置扫描方向/颜色顺序：`0x36`；
5. 使用 `0x2A/0x2B` 设置列、行窗口；
6. 使用 `0x2C` 连续写显存；
7. 开启显示 `0x29`。

STM32 示例中的 GPIO 翻转和 SPI 写法与 MSPM0 外设不同，因此没有直接复制。
新驱动使用可注入总线回调，主机测试可以记录命令序列和绘图边界。

## 3. 最终接线

| 彩屏引脚 | MSPM0 接法 | 说明 |
|---|---|---|
| GND | GND | 必须共地 |
| VCC | 3V3 | 使用 3.3 V 供电 |
| SCL | PB9 | SPI1 SCLK |
| SDA | PB8 | SPI1 PICO/MOSI |
| CS | PA12 | 软件控制片选 |
| DC / RS | PA13 | 命令/数据切换 |
| RES | PA17 | 屏幕硬件复位 |
| BL | 3V3 | 固定全亮，不由 GPIO 直接供背光 |

本接线已按实际地猛星排针功能图修正。芯片封装虽然存在 PB10、PB11 和 PB14，
但该开发板没有把这三个引脚引到两侧排针，因此不能作为实物接线点。

4 位设定身份 ID 改为：

| 位 | MSPM0 引脚 | 电气逻辑 |
|---|---|---|
| bit0 | PB0 | 内部上拉，接地为 1 |
| bit1 | PB1 | 内部上拉，接地为 1 |
| bit2 | PB2 | 内部上拉，接地为 1 |
| bit3 | PB3 | 内部上拉，接地为 1 |

接电前仍需按实物核心板丝印做通断核对，确认这些引脚已经引出且没有被板载外设占用。

## 5. 软件实现

### 5.1 ST7735S 驱动

`st7735s.c/.h` 实现：

- 可注入 CS、DC、RESET、SPI write、delay；
- ST7735S 初始化；
- RGB565 转换；
- 地址窗口、像素、矩形、直线；
- 5×7 ASCII 文字和 2 倍文字；
- 所有绘图边界裁剪；
- 不使用约 40 KB 全屏缓存。

文字的完整可见路径采用一个字符一次窗口写入，避免逐像素重复发送地址命令。

### 5.2 角度安全

工程沿用已有 `LockPositionSolution.angle_valid`，没有重复增加
`bearing_valid`：

- 3/4 锚点有效求解：允许 `angle_valid=true`；
- 两锚点：距离和显示角度均可输出，但 `angle_valid=false`；
- 降级到两锚点、保持、丢包或失败：不能开锁；
- 显示格式层接受 `angle_valid` 或 `angle_held`；后者表示仅供显示的保持值。

### 5.3 UI

正式 UI 使用 128×160 竖屏：

- 深蓝黑背景、白色正文、青色实时数据；
- 绿色表示通过/开锁；
- 红色表示拒绝/锁定；
- 黄色表示等待或角度无效；
- 中央为方向弧线、方向指针和 2 倍角度文字；
- 底部整条状态栏显示 `LOCKED` 或 `OPEN`。

静态框架只在首次显示时绘制，动态区局部刷新，刷新间隔统一为 500 ms，即
2 Hz。UWB UART 使用中断环形缓冲，刷屏期间收到的数据先进入缓冲区。

## 6. 屏幕演示固件

`screen_demo_main.c` 每 3 秒自动切换：

1. 红、绿、蓝、白、黑色块；
2. `SET ID 1010 / KEY ID 1010 / AUTH PASS / +30 deg / OPEN`；
3. `SET ID 1010 / KEY ID 0110 / AUTH FAIL / -18 deg / LOCKED`；
4. `KEY ID ---- / ANGLE -- / LOCKED`。

其中角度和身份数据均为演示测试数据，不代表实测定位结果。
