# 比赛当天快速流程

1. 三台电脑先执行 `npm run git:pull`，确认都在同一 `main` 提交。
2. 负责人把正式题目原文放入 `比赛文档/`，创建“赛题拆解”任务，禁止凭记忆转述关键指标。
3. 三人分别创建任务，负责人字段使用各自 GitHub username；硬件、控制、视觉尽量编辑不同 JSON 和代码目录。
4. 每完成一个可验证节点，追加 `progress` 或 `testResult` 事件，并记录仪器条件、版本和结果。
5. 发现故障立即创建问题；会阻塞主线时设置 `blocking: true` 并关联任务。
6. 每次换电脑或换人前追加 `handoff` 事件，写清当前状态、下一步、风险和所需设备。
7. 小步提交；提交前 `npm run validate`，然后走安全提交与推送。
8. 拉取出现脏工作区、冲突或分叉时立即停手，按 `03-冲突停手与人工处理.md` 处理。
9. 每个阶段执行 `npm run overview`，用总览核对未完成任务和阻塞问题。
