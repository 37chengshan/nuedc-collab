# 三人协作手册

本手册给三位不熟悉 Git 的队员使用。正常协作以仓库中的 JSON 文件和安全脚本为准；GitHub 只负责在三台电脑之间同步已经确认的提交。

## 先读哪一份

1. 首次使用电脑：[`01-三台电脑首次准备与启动.md`](01-三台电脑首次准备与启动.md)。
2. 安全同步或提交：[`02-网站内安全Git五步确认.md`](02-网站内安全Git五步确认.md)。
3. 出现红色冲突、分叉或不确定提示：立刻打开 [`03-冲突停手与人工处理.md`](03-冲突停手与人工处理.md)。
4. 每天开赛、交接和关闭事项：[`04-成员职责与JSON约定.md`](04-成员职责与JSON约定.md) 与 [`05-每日协作与交接.md`](05-每日协作与交接.md)。
5. 设备、网络或断电：[`06-故障排查备份与赛场应急.md`](06-故障排查备份与赛场应急.md)。

## 所有人共同遵守的四条

1. **先检查远端，再开始改。** 看到“落后于远端”、网络错误或身份错误，先停下同步问题，不在旧状态上继续抢改同一文件。
2. **一项记录一个当前负责人。** 任务、问题和已认领想法只由 `owner` 修改；评论、测试、交接和决定另建事件。
3. **脚本每一步都核对。** 拉取、提交、推送均须走“查看 → 填写 → 复核 → 确认 → 结果”五步，不能跳步。
4. **冲突先停手。** 禁止 force、rebase、reset、自动 merge、stash；也不要用命令行“试试看”。

赛题尚未确定时，本手册及配套模板只记录能力、事实、风险和待验证假设，不把小车、MSPM0、天猛星/地猛星或 K230 预写成最终方案。
