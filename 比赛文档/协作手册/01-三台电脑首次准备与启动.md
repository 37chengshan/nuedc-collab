# 三台电脑首次准备与启动

三位队员各用自己的 GitHub 账号、提交署名和本机配置，不共享密码、Token 或 `.本机配置/`。

## 队长先准备一次

1. 在 GitHub 创建团队仓库并邀请另外两位成员。
2. 确认默认分支为 `main`。
3. 把真实克隆地址发给全队；当前本地仓库尚未配置 `origin`，所以本文不虚构地址。
4. 确认三人的真实 GitHub username，用真实记录替换 `teammate-hardware`、`teammate-vision` 占位成员。

## 每台电脑执行

```bash
git --version
node --version
npm --version
```

Node.js 需要 20 或更高版本。

设置本人提交署名：

```bash
git config --global user.name "本人姓名"
git config --global user.email "本人GitHub绑定邮箱"
```

克隆与安装：

```bash
git clone <真实仓库地址>
cd <仓库目录>
npm install
npm run build
```

登记本人。用户名必须与 GitHub 完全一致：

```bash
npm run agent -- init-member \
  --username 本人GitHub用户名 \
  --roles hardware,firmware \
  --responsibilities "本人负责内容" \
  --local
```

`--local` 写入 `.本机配置/settings.json`，该目录被 Git 忽略，不能提交。

验收：

```bash
npm run validate
npm run overview
npm run git:status
```

三台电脑都应能完成构建、校验与总览生成。前端已归档，当前没有需要启动的网页端口或本地 API。
