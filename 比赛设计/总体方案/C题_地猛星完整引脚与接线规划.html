041.77 英寸 ST7735S

`参考资料/屏幕/` 中的代码、模块图和实物照片都是当前屏幕的配套资料。 该屏为 GMT177-01，128RGB×160，ST7735S 或兼容驱动，使用 SCK、SDA、CS、RS、RES 串行写入； VCC 范围 3.0～5.0V，本项目优先使用 3.3V。

8 针排针信号地猛星接法
1GND接 GND
2VCC接 3V3
3SCL / SCKPB9 / SPI1-SCK
4SDAPB8 / SPI1-PICO（MOSI）
5RESPB20 / GPIO
6DC / RSPB24 / GPIO
7CSPB6 / SPI1-CS0
8BL / LEDA接 3V3，背光常亮
第 8 针是 3V3，不是 PB18。 当前按常亮方式把 BL/LEDA 直接接地猛星 3V3。只有以后需要调光时才增加 MOSFET，并可选用 PB18 控制；默认不占用 PB18。

05四位拨码

每个开关一端接 GPIO，另一端接 GND；GPIO 开启上拉。

GPIO 一侧

  • bit0 → PA28
  • bit1 → PA31
  • bit2 → PA13
  • bit3 → PA16

公共侧

  • 四个开关的另一端全部接 GND
  • 断开时读取高电平
  • 闭合时读取低电平
  • 业务需要 ON=1 时在软件中取反

06声光与门锁

功能引脚外部电路建议行为
红色 LEDPA14串联 330Ω锁定或拒绝时点亮
绿色 LEDPA15串联 330Ω合法开锁时点亮
蜂鸣器PA12NPN/NMOS 驱动有源 GPIO；无源 PWM
门锁执行器PB19MOSFET/继电器/H 桥只输出控制信号
迎宾 LEDPA7串联 330Ω可选，迎宾区点亮
GPIO 不能直接带蜂鸣器和门锁负载。 蜂鸣器、电磁铁、电机和继电器线圈必须使用驱动器件；感性负载加续流二极管。

07必须保留的引脚

禁止占用

  • PA5 / PA6：40 MHz HFXT
  • PA19 / PA20：SWDIO / SWCLK
  • NRST：硬件复位
  • 3V3、5V、GND：按电源域使用

建议保留

  • PA17 / PA18：板载串口与 BSL 路径
  • PB2 / PB3：I2C1 扩展
  • PB7：SPI1 MISO
  • PA27：ADC 扩展
