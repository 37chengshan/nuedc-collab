# 2026 电赛 B 题 MCU 后端总体方案

> 官方题目原文：[B题_“无源”交流电流表及无线读表器.pdf](../../比赛文档/官方题目/B题_“无源”交流电流表及无线读表器.pdf)

## 1. 项目目标

题目：**“无源”交流电流表及无线读表器**

当前分工：

- **老师负责**：取电、传感、模拟信号调理。
- **我们负责**：模拟信号进入地猛星 MSPM0G3507 之后的全部数字部分，包括 ADC 采样、RMS、电流标定、OLED 显示、地址识别、报警、串口通信和后续无线通信。

核心指标：

- 电流测量范围：0.1~2 A
- 显示交流有效值 RMS
- 相对误差绝对值 ≤0.5%
- 4 位编码开关设置电流表地址
- 无线模块可插拔
- 读表器后续完成手动读取、自动搜索、报警、历史数据和趋势曲线

---

## 2. 总体数据链

```text
老师前端
取电 → 电流传感 → 信号调理
                    ↓
                模拟电压
                    ↓
          PA27 / A0-0 ADC输入
                    ↓
            MSPM0G3507 ADC
                    ↓
            采样 / 滤波 / 去偏置
                    ↓
                RMS计算
                    ↓
                标定修正
                    ↓
              实际电流值 I
                    ↓
      ┌─────────────┼─────────────┐
      ↓             ↓             ↓
   OLED显示       状态判断       地址读取
                  LOW/NORMAL/OVER
      └─────────────┼─────────────┘
                    ↓
               数据协议封包
                    ↓
                  UART
                    ↓
          可插拔无线通信模块
                    ↓
                无线读表器
```

## 3. 当前硬件

### 必需

- 地猛星 MSPM0G3507 开发板
- I2C OLED
- Type-C 数据线
- 面包板、杜邦线
- 4 位拨码/编码开关
- 少量 1kΩ、10kΩ 电阻
- 可调直流电源，用于 ADC 前期测试

### 临时无线

- HC-05 蓝牙模块可用于验证 UART 无线通信
- 正式无线模块到货后直接替换

---

## 4. 当前引脚规划

```text
PA27 / A0-0    → 模拟信号 ADC 输入

PB2            → OLED SCL
PB3            → OLED SDA

PA8 / UART1-TX → 无线模块 RX
PA9 / UART1-RX → 无线模块 TX

PB6~PB9        → 4 位地址开关
```

板载 Type-C / 串口用于前期有线调试。

## 5. 开发顺序

### 阶段 1：MCU 基础

```text
烧录程序
→ 串口输出正常
```

### 阶段 2：ADC 测试

先不用老师电路，用可调直流电源模拟输入。

```text
可调电压 0.5~2.5V
→ PA27
→ ADC
→ 串口/OLED 显示 ADC 和电压
```

目标：验证模拟输入 → ADC → MCU 全链路。

### 阶段 3：接老师模拟信号

确认老师输出信号类型：

- 若为交流波形：连续 ADC 采样，数字计算 RMS
- 若为直流量：ADC + 滤波 + 标定

交流方案优先：

```text
2 kS/s 采样
→ 400 点 / 200 ms
→ 求平均 offset
→ 每点减 offset
→ 平方
→ 平均
→ 开方
→ RMS_raw
```

### 阶段 4：标定

用标准电流表测试：

```text
0.10A
0.20A
0.50A
1.00A
1.50A
2.00A
```

记录：

```text
标准电流 Istd
MSPM0 RMS_raw
```

第一版：

```text
I = k × RMS_raw + b
```

若误差无法达到 0.5%，改为分段线性标定。

### 阶段 5：OLED + 状态

显示：

```text
ADDR: 03
I: 0.523 A
STATUS: NORMAL
```

状态：

```text
I < 0.2A     → LOW
0.2~2A       → NORMAL
I > 2A       → OVER
```

### 阶段 6：地址

4 位 GPIO 读取 0~15 地址。

### 阶段 7：有线串口协议

先通过电脑串口调试：

```text
ADDR=03
CURRENT=523mA
STATUS=NORMAL
```

### 阶段 8：无线

UART 协议保持不变：

```text
MSPM0
→ UART1
→ HC-05（临时）
→ 正式无线模块（最终）
```

## 6. 软件结构建议

```text
main.c
├── adc.c
├── current.c
├── calibration.c
├── display.c
├── address.c
├── alarm.c
├── protocol.c
└── wireless.c
```

职责：

- `adc.c`：ADC 初始化和采样
- `current.c`：滤波、去偏置、RMS
- `calibration.c`：RMS → 电流
- `display.c`：OLED
- `address.c`：4 位地址
- `alarm.c`：LOW / NORMAL / OVER
- `protocol.c`：通信数据帧、CRC
- `wireless.c`：UART 和无线模块

---

## 7. 通信协议建议

```text
AA 55 | VER | TYPE | ADDR | SEQ | CURRENT_mA | FLAGS | CRC16
```

例如：

```text
CURRENT=523
```

代表：

```text
0.523 A
```

状态位：

```text
bit0 = LOW
bit1 = OVER
bit2 = SENSOR_FAULT
bit3 = ADC_CLIP
```

## 8. 当前第一目标

现阶段不要先做无线。

第一闭环：

```text
可调直流电压
→ PA27
→ ADC
→ 串口显示 ADC/Voltage
→ OLED 显示
```

第二闭环：

```text
老师模拟信号
→ ADC
→ RMS
→ 标定
→ 0.xxx A
→ OLED
```

第三闭环：

```text
电流值
→ 地址
→ 状态
→ 串口协议
→ HC-05
→ 正式无线模块
```

---

## 9. 当前需要老师提供的接口信息

1. 模拟输出是交流波形还是直流量
2. MCU 侧供电电压
3. 0.1A、1A、2A 时模拟输出电压范围
4. 若是交流波形，是否已经加入直流偏置
5. 2.2A 时信号是否会超过 ADC 输入范围
6. MCU 侧是否已经与强电安全隔离

---

## 10. 一句话方案

**老师完成取电、传感和调理，我们用 MSPM0G3507 从 PA27 ADC 采样模拟信号，计算 RMS 并标定成电流，通过 OLED 显示地址、电流和报警状态，再通过 UART 接可插拔无线模块，最终由读表器完成无线读取、离线判断、历史记录和趋势显示。**
