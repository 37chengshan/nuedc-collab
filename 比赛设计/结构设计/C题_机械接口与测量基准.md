# C 题机械接口与测量基准

本文件是数字钥匙、门锁定位骨架和背面操作面板的 CAD 输入规范。最终 STL/3MF 只能使用实测尺寸发布；厂商名义尺寸和照片估算不得冒充装配尺寸。

## 1. 坐标与标记

- `O=(0,0,0)`：门锁圆柱中心在天线参考高度平面上的投影。
- `+Y / FRONT`：智能门锁正前方。
- `+X / RIGHT`：面向 FRONT 时的右侧。
- `+Z / UP`：竖直向上。
- `R0=300 mm`：官方径向距离零点边界。
- `KEY REF`：数字钥匙现场测距使用的唯一定位点，优先与钥匙 UWB 天线参考点重合或给出固定偏置。
- `A1/A2/A3`：三枚门锁 UWB 天线参考点，不是 PCB 中心或安装孔中心。

所有零件必须带不会装反的 FRONT/BACK 标记；锚点座必须标记 A1、A2、A3。

## 4. 需要的测量照片

每个部件至少提供：

1. 正面全景，尺或游标卡尺与长边同平面。
2. 背面全景，能看清孔位、焊点和丝印。
3. 长、宽、总高三张测量照片。
4. 孔距和孔径照片；无孔时标明允许夹持的非器件边。
5. 连接器侧视图，包含线缆插入后的弯折空间。
6. UWB 天线局部图，标出天线端、推荐朝向和不可遮挡范围。

照片透视不能替代数值；无法用卡尺测量的尺寸应标注测量方法和估计误差。

## 7. 参数化零件边界

### 7.1 UWB 朝向试验座

- 板卡夹持区由实测外廓和器件禁区驱动。
- 支持 `0°、±15°、±30°、±45°` 可重复定位。
- 天线端无遮挡，夹持和紧固点不进入天线禁布区。
- 先打印一个座和公差试片，装配通过后再复制三份。

### 7.2 紧凑型免拼壳门锁

- 主体由 `268×268×76 mm` 一体底壳和 `266×266×17.2 mm` 一体上盖组成，均能在 300×300 mm 热床单次打印，不使用扇区拼接或胶水。
- 上下壳通过定位唇边和四处卡扣快拆；上盖外表面朝下打印，避免内腔大面积桥接。上盖内侧布置 8 根 `4×2.4 mm` 径向加强筋，加强筋外缘半径 `100 mm`，与中心半径 `108 mm`、半径 `3.2 mm` 的支撑柱保留至少 `1 mm` 参数净距。
- 三枚 UWB 使用同规格滑入式卡匣并名义等高固定，不能靠软连接维持锚点坐标。
- `84×64 mm` 背面板承载显示、拨码、LED 和调试口；观看和操作不得要求人员进入前方 ±45°。
- 4 位拨码操作口必须永久标出从左到右 `bit3、bit2、bit1、bit0`，并标出 `ON` 朝显示器方向。拨码由独立固定笼和两枚 M2.5 螺钉固定，不能依靠热熔胶或悬空导线定位。
- 显示界面至少同时显示“门锁当前拨码 ID”“接收到的钥匙 ID”“MATCH/FAIL 识别结果”和锁状态，才能证明修改后的身份 ID 被重新采样并参与识别。
- 线缆必须应力释放，维护主控、显示器或电池不能移动锚点座。
- 门锁装配名义包络 `Ø276×100 mm`，显著小于 `Ø600×300 mm` 官方上限；官方径向零点仍按第 1 节的 `R0=300 mm` 定义。

### 7.3 数字钥匙壳

- 采用底壳、上盖和独立可替换控制面板；控制面板名义外廓 `66×34 mm`，这样开关尺寸变化时无需重打整个钥匙壳。
- 启动按键孔、状态 LED 孔和拨动槽必须真实贯通；按键帽采用捕获式结构，按键名义行程 `0.8 mm`，拨动滑块名义行程 `8 mm`。
- 一键启动可盲操作，状态 LED 可见；拨动开关用途必须由电路/固件定义并在壳体上标识，不能只做装饰滑块。
- 503040 电池、候选电源板和 UWB 在 X 方向分别以 `-26.5、8.5、35 mm` 为中心，占位检查要求相邻部件至少 `1 mm` 净距；实际线束、保护板和连接器仍需装配验证。
- 天线端无电池、金属螺钉和厚壁遮挡。
- USB-C 若保留，只作为调试/充电接口；最终运行仍须证明由电池供电。
- 外壳上永久标注 KEY REF。

## 8. 发布门槛

当前 `v0.4` 已达到“可拆钥匙控制面板、单热床免拼壳软件候选”，但依次满足后才能标为“实物可装配首版”：

1. 板型和全部关键尺寸已实测。
2. UWB 天线朝向试验完成，固定角度已有数据依据。
3. 打印工艺和公差试片通过。
4. CAD 包络检查通过：钥匙不超过 120×80×40 mm；门锁全部结构不超过直径 600 mm、高 300 mm。
5. STL/3MF 无非流形面、反法线、悬空薄壁和不可达紧固件。
6. 首版装配后复测 A1/A2/A3，并将实测坐标交给定位程序。
