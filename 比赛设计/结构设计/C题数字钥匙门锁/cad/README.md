# C 题数字钥匙与紧凑型门锁参数化 CAD

本目录保存可复现的参数化几何与 OrcaSlicer 作业源。当前版本为 `v0.4 可拆钥匙控制面板软件候选版`；`v0.1` 裸露定位架、`v0.2` 596 mm 扇区拼壳和缺少完整钥匙操作机构的 `v0.3` 仅保留为历史方案，不再作为首选打印结构。

## 当前结构

- 数字钥匙：名义包络 `105×58×33 mm`，由底壳、上盖、`66×34 mm` 可替换控制面板、捕获式启动按键帽、拨动滑块和电池卡扣组成。控制面板具有真实贯通的启动按键孔、`4 mm` 状态 LED 孔和 `15×5.4 mm` 拨动槽，并为候选 `50×20×1.6 mm` 控制板保留导轨和触发行程。
- 钥匙内部：503040 电池中心 X=`-26.5 mm`、`25×22×8 mm` 候选电源板中心 X=`8.5 mm`、UWB 中心 X=`35 mm`；参数检查要求相邻占位件至少 `1 mm` 净距。控制板、按键和拨动开关的具体实物尺寸仍待复核。
- 智能门锁：名义包络 `Ø276×100 mm`，主壳包含 `268×268×76 mm` 一体底壳和 `266×266×17.2 mm` 一体上盖，均可在 CR-3040D 单次打印，不需要扇区拼接或粘接；上盖增加 8 根 `4×2.4 mm` 径向加强筋。
- 三 UWB 节点：使用相同的 `33×23×8 mm` 滑入式快拆卡匣；当前 A1/A2/A3 为设计候选，名义天线参考高度 `Z=48 mm`。
- 背面服务面：采用 `84×64 mm` 可拆面板，安装 1.77 英寸 ST7735S、4 位拨码、红绿锁态 LED、迎宾 LED 和调试口。拨码操作口标明 `bit3 → bit0`，`ON` 方向朝向显示器。
- 显示器：PCB `56×34 mm`、可视区名义值 `38.5×32 mm`、孔距 `52×30 mm`、孔径 `2.5 mm`；背面安装并使用独立 `63×41×3 mm` 压框。
- 4 位拨码：名义外廓 `12.5×11.72×9.5 mm`，使用独立 `27.5×14.82×14.05 mm` 固定笼和两枚 M2.5 螺钉夹持；操作口四周各保留 `3 mm` 手指/工具余量。
- 主壳内部：为 `100×55 mm` PCB 和 `68×55×19 mm` 门锁电池组预留安装区；孔位未知阶段采用边缘定位和独立卡扣。

## 快拆与冗余

1. 钥匙壳使用裙边定位和两处卡扣；控制面板为独立快拆件，按键帽采用捕获式结构，拨动滑块压配到开关执行杆，电池卡扣、UWB 和电源板可独立维护。
2. 门锁上下壳使用定位唇边和四处卡扣，不使用胶水；上盖外表面朝下打印，内唇和卡扣向上。
3. 三个 UWB 使用同规格滑入式卡匣，局部接口或天线方向修订时只重打卡匣。
4. 显示器、拨码、背面板和电池均使用独立压框、固定笼或卡扣，电子接口修订时不必重打主壳。
5. 配置保留 XY 单边 `0.45 mm`、Z `0.35 mm` 候选间隙，并要求卡扣至少完成 20 次循环验收；在公差试片结果确认前不得标记为实机验证值。

## OrcaSlicer 作业

以下命令读取本机已经配置的 `cr CR-3040d 0.4 nozzle` 启停 G-code，生成独立的 PETG 保守工艺副本并切片，不修改 OrcaSlicer 用户配置：

```bash
python3 比赛设计/结构设计/C题数字钥匙门锁/cad/prepare_orca_job.py \
  --config 比赛设计/结构设计/C题数字钥匙门锁/cad/parameters_v0_4.json \
  --models 生成内容/3D打印/C题/v0.4 \
  --output 生成内容/3D打印/C题/v0.4/orcaslicer \
  --slice \
  --allow-provisional-clearance
```

按部件类型分别居中切片：

```bash
python3 比赛设计/结构设计/C题数字钥匙门锁/cad/prepare_orca_job.py \
  --config 比赛设计/结构设计/C题数字钥匙门锁/cad/parameters_v0_4.json \
  --models 生成内容/3D打印/C题/v0.4 \
  --output 生成内容/3D打印/C题/v0.4/orcaslicer/individual_parts \
  --individual-parts \
  --slice \
  --allow-provisional-clearance
```

该模式为 13 种部件分别生成 G-code，每组模型中心位于热床中心 `(150,150)`。按钮帽和拨动滑块各 3 个，钥匙电池卡扣和拨码固定笼各 2 个；UWB 卡匣与门锁电池卡扣按装配数量分别为 3 个和 2 个，其余各 1 个。

切片基线：PETG `1.75 mm`、材料标称喷嘴温度 `235～270 ℃`、热床 `80～90 ℃`、常规推荐速度 `40～100 mm/s`、喷嘴 `0.4 mm`、层高 `0.20 mm`、首层/常规喷嘴 `255/250 ℃`、首层/常规热床 `90/85 ℃`、3 圈墙、15% gyroid、外墙/内墙/小轮廓/填充/移动 `45/60/40/70/100 mm/s`。首层采用 `0.48 mm` 线宽和 `15 mm/s` 轮廓与填充，桥接采用 `30 mm/s`；这两项是为首层粘附和跨桥质量保留的专项低速，不作为常规材料速度。另使用 `60%` 首层移动、固定 `outer_only` 的 `7 mm` 无间隙 brim，并关闭前 5 层模型风扇。

安全启动序列不再直接复用原预设中的过量擦料代码：热床设为首层 `90 ℃` 的同时，喷嘴并行预热到 `220 ℃`；归零后抬高到 `Z=10 mm` 等待热床，热床到温后把喷嘴升到首层 `255 ℃`，最后在床前缘打印两条各 `100 mm / E10 mm` 的擦料线。进入后续层后喷嘴降到 `250 ℃`、热床降到 `85 ℃`。

验证 3 份 G-code 的坐标、温度、速度和加速度：

```bash
python3 比赛设计/结构设计/C题数字钥匙门锁/cad/validate_orca_gcode.py \
  --config 比赛设计/结构设计/C题数字钥匙门锁/cad/parameters_v0_4.json \
  --gcode-dir 生成内容/3D打印/C题/v0.4/orcaslicer/gcode \
  --manifest 生成内容/3D打印/C题/v0.4/orcaslicer/print_manifest.json \
  --output 生成内容/3D打印/C题/v0.4/orcaslicer/gcode_validation.json
```

切片不把 16 个实例一次性交给 Orca 自动跨盘排布。脚本先为每盘计算确定性 XY 变换，按 `7 mm` brim 加 `2 mm` 净距检查包络，再生成 3 个不携带自定义预设的标准 3MF；随后关闭 `--arrange`，逐盘独立切片。校验器会同时读取首层命名对象路径和对象标记外的 brim 路径，核对 `1 + 1 + 14` 个唯一实例、包含 brim 的实际足迹、两两重叠、未归属挤出及 5 mm 床边余量；任何缺件、意外对象、正面积重叠、无法归属的首层挤出或越过床边余量都会使验证失败。

## 当前输出与状态

- `生成内容/3D打印/C题/v0.4/`：13 种 STL、16 个打印实例、4 张装配/爆炸 PNG 和几何验证报告；13/13 STL 重载检查通过。
- `生成内容/3D打印/C题/v0.4/orcaslicer/projects/`：3 个逐盘标准布局 3MF，分别对应一体底壳、一体上盖和 14 个小件；文件不内嵌自定义预设，Orca 已实际载入并用于切片。
- `生成内容/3D打印/C题/v0.4/orcaslicer/gcode/`：3 份安全启动版 G-code；Orca 估算合计 `631.04 g`、`2d 1h 59m 34s`。
- 第 1 盘为一体底壳，第 2 盘为一体上盖，第 3 盘包含钥匙壳、控制面板、启动按键帽、拨动滑块、背面板、显示压框、拨码固定笼、电池卡扣和 3 个 UWB 卡匣。
- `生成内容/3D打印/C题/v0.4/orcaslicer/trial/`：3 份逐盘首层验证 G-code；每份只打印对应盘首层，随后自动抬高、关喷嘴和热床。
- `gcode_validation.json` 与 `first_layer_trial_validation.json`：完整文件和首层文件均为 3/3 通过；实际首层对象数为 `1、1、14`，命名对象重叠和包含 brim 的足迹重叠均为 `0`，未归属首层挤出均为 `0`。喷嘴等待/首层/常规目标为 `220/255/250 ℃`，首层/常规热床为 `90/85 ℃`，均位于材料标签范围；三盘首层全部挤出范围分别为 `9.361～290.639`、`10.361～289.639` 和 X `6.208～293.792`/Y `40.858～259.142 mm`，保留至少 5 mm 床边余量。

旧版聚合 3MF 曾因未注册预设标识导致 OrcaSlicer 2.4.2 在 `Sidebar::update_presets` 阶段崩溃，且一次跨盘自动排布生成的第 3 盘存在真实路径重叠。该路径已经停用：当前 3MF 仅保存几何和确定性位置，3 盘分别切片，用户预设源文件的切片前后 SHA-256 也必须一致。Repetier-Host 仅用于查看和发送已由 OrcaSlicer 生成的 G-code，不使用其旧版内置 Slic3r 参数重新切片。

2026-07-29 的 v0.3 第 3 盘首次试打因床面残留胶层/薄膜、打印物卷曲并被喷嘴触碰而中止。用户移除该胶层后现场反馈打印已恢复正常；这足以关闭“平台残留导致立即卷起”的故障判断，但尚不能代替 v0.4 首层、整盘打印、尺寸复测和装配循环证据。

以上结果代表“参数化建模、网格校验和软件切片通过”，不代表已实机打印或装配。最终冻结仍需：公差试片最佳档位、UWB Type-C 方位/天线禁布区、100×55 PCB 孔位与最高器件、ST7735S 厚度/排针突出高度/连接器方向、钥匙 `50×20 mm` 控制板及启动按键/拨动开关/LED/蜂鸣器/电源板和紧固件实测数据，以及装配后的 A1/A2/A3 天线坐标。
