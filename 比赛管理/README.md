# 文件通讯系统

这里是三名队员与 Agent 的共享通信层。活动记录一律“一条记录一个 JSON 文件”，避免三台电脑同时改一个大文件。

- `任务/`：可执行工作、负责人、验收条件和状态。
- `问题/`：故障、阻塞、临时绕过和最终解决。
- `想法/`：尚未进入执行阶段的假设与方案点子。
- `事件/`：进度、测试结果、决策、状态变化和交接历史。
- `成员/`：文件名和 `githubUsername` 必须一致。
- `模板/`：字段参考，不作为活动记录加载。
- `Schema/`：运行 `npm run schemas` 生成。

`teammate-hardware` 和 `teammate-vision` 是明确的非激活占位账号。确定队友真实 GitHub username 后，分别运行 `init-member` 创建真实记录并删除占位文件。

机器写入入口：`npm run agent -- help`。人类/Agent 都不应绕过协议直接批量改 JSON。
